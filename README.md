# AI Finder

Каталог ШІ-сайтів на публічному API [FreeSerp](https://freeserp.ai/docs.php)
(без ключа та реєстрації; головні сторінки сайтів `index=sites`, ніша `category=ai`).

**Демо:** https://ws-58.ws.semalt.dev/ · копія на GitHub Pages: https://golfcountry24-rgb.github.io/AI-Finder/
**План сайту** (мета, аудиторія, сторінки, структура): [PLAN.md](PLAN.md)

## Що зроблено

- **Сторінки:** Каталог, Нові ШІ (стрічка за датою запуску), Про проєкт, сторінка сайту
  `/site/<domain>`, Збережені, Порівняння; плюс сторінка 404.
- **Пошук** по API (`q`) із затримкою 400 мс, індикатором пошуку й кнопкою очищення.
- **Фільтри** за 15 реальними категоріями ШІ з API та перемикач «Лише ШІ-продукти» (`ai_startups=1`).
- **Сортування:** релевантність, нові, старі, рейтинг домену, A → Z.
- **«Показати ще»** — посторінкове завантаження (захищене від подвійного кліку, з урахуванням межі API в 10 000).
- **Картка сайту** в модальному вікні (на мобільному — нижня панель) і **власна сторінка сайту**
  `/site/<domain>`: опис, категорії-посилання на фільтр, рейтинг, дати, технології, схожі сайти,
  кнопка «Скопіювати посилання». На PHP-хостингу її віддає `site.php` уже з потрібними
  `title`/`description`/`canonical`/JSON-LD і текстом профілю в HTML; невідомий домен — справжній 404.
- **Збережені:** зірочка на картці, у вікні та на сторінці сайту; список у `localStorage`,
  синхронізується між вкладками, лічильник у меню, сторінка `/favorites`.
- **Порівняння:** до 4 сайтів поруч у таблиці (опис, категорії, рейтинг, запуск, перша поява,
  на чому зроблено, вебсервер, TLD, HTTP-статус) з позначками «найвищий» / «найновіший».
  Плаваюча панель вибраних сайтів; адреса `/compare?d=a.com,b.com` сама відтворює таблицю,
  тож нею можна поділитися.
- **Денна / нічна тема:** перемикач у шапці; доки вибору немає — як у системі. Тема ставиться
  до першого кадру, тому темна сторінка не «блимає» білим.
- **Стан фільтрів в адресі** (`/?q=&cat=&sort=`, `/new?cat=`), тому посиланням можна поділитися;
  кнопка «Назад» скасовує зміну фільтра. Під час завантаження нових результатів попередні
  лишаються на екрані (приглушені), а сторінка не «стрибає».
- **Стани завантаження, помилки та порожнього результату.** Помилка показується з кнопкою «Спробувати ще», порожній результат — з кнопкою скидання фільтрів. Запит, що висить довше 15 с, завершується зрозумілою помилкою.
- **Мови:** українська та англійська з перемикачем UA/EN. Дати, числа й відмінки локалізовані.
- **Адаптивність:** 1440 / 768 / 375 px.
- **Доступність:** доступ з клавіатури та видимий фокус.
- **Анімації:** плавна поява контенту знизу вгору (Anime.js), картки з'являються під час прокрутки.
- **Лише реальні дані API.** Якщо поля немає, воно не показується; нічого не вигадано.
- **Пререндер:** під час збірки поточні списки (каталог і нові ШІ) записуються в `index.html` і
  `new.html` звичайним HTML з посиланнями на `/site/<domain>`, а ці сторінки додаються в `sitemap.xml`.
  Пошуковики без JavaScript бачать контент; відвідувачі з JS його не бачать (його замінює застосунок).
  Якщо API під час збірки недоступний, збірка просто йде без пререндеру (`PRERENDER=0` вимикає його).
- **SEO:** чисті адреси (`/new`, `/about`) замість `/#/`; для кожної сторінки окремий HTML зі своїми
  `title`, `description`, `canonical`, Open Graph / Twitter-картками та JSON-LD (schema.org);
  `sitemap.xml`, `robots.txt`, OG-зображення 1200×630; справжній статус 404 для неіснуючих адрес;
  коректна ієрархія заголовків. Lighthouse: SEO 100, Accessibility 100, Best Practices 100.
- **PHP-проксі.** API надсилає некоректний CORS-заголовок, тому запити йдуть через маленький
  PHP-проксі на тому ж домені (`api/freeserp.php`). Є й альтернатива для хостингу без PHP —
  Cloudflare Worker.

- **Якість коду:** ESLint (зокрема правила React Hooks / React Compiler), TypeScript для моделі
  даних API (`src/types/api.ts`, `src/services/freeserp.ts`, `npm run typecheck`), 32 юніт-тести
  Vitest і 12 e2e-сценаріїв Playwright (десктоп і мобільний, API підмінено фікстурами, мережа не
  потрібна). Усе запускає GitHub Actions ([.github/workflows/ci.yml](.github/workflows/ci.yml)).
  Підсумок самоперевірки — [docs/REVIEW.md](docs/REVIEW.md).

**Стек:** React 19, Vite 8, React Router 7, CSS Modules, Anime.js 4, TypeScript (модель API); ESLint, Vitest, Playwright. UI-кітів немає.

## Як запустити

Потрібен Node.js 20.19+ (або 22.12+).

```bash
npm install
npm run dev        # режим розробки, http://localhost:5173
```

Продакшн-збірка:

```bash
npm run build      # створює папку dist/
npm run preview    # перегляд збірки локально
```

Перевірки:

```bash
npm run lint       # ESLint
npm run typecheck  # TypeScript (модель даних API)
npm run test       # юніт-тести (Vitest)
npm run check      # lint + typecheck + test + build разом
npm run test:e2e   # e2e-тести Playwright (перший раз: npx playwright install chromium)
```

Публікація: завантажити **вміст** `dist/` на сервер із PHP. Для чистих адрес (`/new` → `new.html`,
`/site/<domain>` → `site.php`) потрібне правило сервера: для nginx — [deploy/nginx.conf](deploy/nginx.conf), для Apache —
`.htaccess`, який уже лежить у `dist/`. Публічна адреса для canonical і sitemap задається
змінною `VITE_SITE_URL` (див. `.env.example`). Node.js на сервері не потрібен.
Деталі (зокрема хостинг без PHP) — у [docs/TECHNICAL.md](docs/TECHNICAL.md).

**GitHub Pages** збирається автоматично ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)):
кожен push у `main` запускає `npm run check` і публікує `dist/`. У Pages немає PHP, тому
запити до API йдуть через PHP-проксі демо-сервера Semalt (`VITE_API_BASE`).

## Обмеження

- **Глибока пагінація.** API віддає не більше 10 000 результатів на один запит (`from + size ≤ 10000`),
  тому «Показати ще» має цю межу.
- **Пошук одного сайту.** У FreeSerp немає фільтра `domain=`, тому сторінка сайту шукає домен через
  `q=<domain>` і бере точний збіг. Сайти поза ШІ-нішею індексу показуються як «не знайдено».
- **GitHub Pages без PHP.** Там `/site/<domain>` відкривається через `404.html`: сторінка працює, але
  сервер віддає статус 404 і загальні мета-теги (потрібні теги ставить уже застосунок).
- **Збережені й порівняння** живуть у браузері: на іншому пристрої їх не буде (поділитися порівнянням
  можна посиланням).

## Структура

```
src/
  types/       TypeScript-модель даних API
  services/    робота з API (freeserp.ts, favicon.js)
  hooks/       завантаження даних, пошук сайту за доменом, debounce, стан у URL
  store/       збережені сайти й порівняння (localStorage)
  theme/       денна / нічна тема
  components/  UI-компоненти
  pages/       Explore, New AI, About, Site, Favorites, Compare, 404
  i18n/        переклади UA / EN
  motion/      анімації (Anime.js)
  seo/         мета-теги, JSON-LD, тексти для пошуковиків, пререндер при збірці
  styles/      дизайн-токени
  utils/       форматування, константи (категорії, сортування)
public/api/    PHP-проксі (freeserp.php, favicon.php, спільний _lib.php)
public/site.php  серверний рендер /site/<domain>
e2e/           e2e-тести Playwright і фікстури API
deploy/        конфіг nginx, Cloudflare Worker
```
