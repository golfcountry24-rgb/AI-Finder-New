# Самоперевірка (code review)

Проєкт переглянуто очима senior frontend-рев'юера: UI, UX, код та інтеграція з API.
Нижче — що знайдено і як виправлено. Кожен баг спершу відтворено в браузері,
після виправлення покрито тестом (тест падає на старому коді).

## Баги

| # | Проблема | Як проявлялась | Виправлення |
|---|----------|----------------|-------------|
| 1 | **Дати зсувались на день** | API віддає `2026-08-13` (опівніч UTC); у часових поясах на захід від UTC картка показувала «12 серп.» | Дати форматуються з `timeZone: 'UTC'` (`src/i18n/index.jsx`) |
| 2 | **Подвійний клік «Показати ще» пропускав сторінку** | два однакові запити `from=24`, а `offset` збільшувався двічі — 24 сайти зникали | Захист від повторного запуску (ref), `offset` рахується від `from` запиту (`useSites`) |
| 3 | **Межа API 10 000** | біля межі «Показати ще» ховалось завчасно або просило `from + size > 10000` | Останній запит зменшує `size`, `hasMore` враховує межу |
| 4 | **Запит без таймауту** | якщо API «висить», завантаження тривало вічно | Таймаут 15 с → помилка `timeout` з кнопкою повтору (`withTimeout` у `freeserp.js`) |
| 5 | **Посилання з API не перевірялись** | `url` з відповіді API потрапляв у `href` як є | `safeUrl()`: лише `http:`/`https:`; записи без домену відкидаються |
| 6 | **Кеш без меж** | in-memory кеш і файловий кеш PHP-проксі лише росли | Ліміт 60 записів у браузері; PHP-проксі час від часу чистить старі файли |

## UX

| # | Проблема | Виправлення |
|---|----------|-------------|
| 7 | Кожна зміна фільтра замінювала список скелетоном — сторінка «стрибала» | Попередні результати лишаються (приглушені, `aria-busy`) до приходу нових |
| 8 | Зміна фільтра глибоко в списку лишала користувача біля футера | Сторінка повертається до фільтрів (`useKeepInView`), лише якщо вони вже за межами екрана |
| 9 | «Назад» після зміни фільтрів одразу залишав сторінку | Фільтри/сортування додають запис в історію; набір тексту в пошуку — ні |
| 10 | Фільтри сторінки «Нові ШІ» губились при оновленні й ними не можна було поділитися | Фільтри в адресі: `/new?cat=…&ai=0` |
| 11 | Мобільне меню не закривалось по Esc чи кліку поза ним | Esc (фокус повертається на кнопку) і клік поза шапкою закривають меню |
| 12 | Перемикач «Лише ШІ-продукти» озвучувався як звичайний чекбокс | `role="switch"` |

## Перевірено після змін

- `npm run check` — без помилок.
- 20 браузерних сценаріїв (пошук, фільтри, сортування, модалка, «Показати ще», мова, меню, навігація, 404) — усі проходять, помилок у консолі немає.
- Попіксельне порівняння скриншотів 1440 / 768 / 375 (EN, UA): дизайн не змінився, відрізняються лише живі лічильники.
- Lighthouse: SEO 100, Accessibility 100, Best Practices 100.
