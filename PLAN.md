# AI Finder — план сайту

Невеликий каталог ШІ-сайтів на публічному API [FreeSerp](https://freeserp.ai/docs.php)
(без ключа та реєстрації; індекс головних сторінок `index=sites`, ніша `category=ai`).

**Демо:** https://ws-58.ws.semalt.dev/

## Мета

Зробити зручний каталог, у якому ШІ-сервіси можна знаходити й порівнювати за тим,
що вони справді роблять, — на основі структурованих даних FreeSerp (опис від ШІ,
категорії, рейтинг домену, дата запуску), а не рекламних текстів. Окремо — швидко
бачити, що з'явилося нещодавно.

## Аудиторія

- Люди, які шукають ШІ-інструменти для роботи, навчання, розробки, створення контенту
  та продуктивності.
- Ті, хто стежить за новими запусками у сфері ШІ.

## Сторінки

| # | Сторінка | Адреса | Що на ній |
|---|----------|--------|-----------|
| 1 | **Каталог** (Explore) | `/` | Пошук, фільтри за категоріями ШІ, перемикач «Лише ШІ-продукти», сортування (релевантність, нові, старі, рейтинг домену, A → Z), сітка карток, «Показати ще», картка сайту в модальному вікні |
| 2 | **Нові ШІ** (New AI) | `/new` | Стрічка найсвіжіших ШІ-сайтів, згрупованих за датою запуску (`went_live`), з фільтром за категорією |
| 3 | **Про проєкт** (About) | `/about` | Мета, аудиторія, звідки дані, короткий опис FreeSerp API та полів, які використовуються |

## Структура

```
Шапка (логотип, меню, перемикач UA/EN)
  → Hero + пошук
  → Фільтри та сортування
  → Каталог ШІ-сайтів (картки)
  → Детальна картка сайту (модальне вікно)
  → Футер
```

## Картка сайту

Назва, favicon, домен, опис від ШІ, категорії ШІ, рейтинг домену (Domain Rating),
дата запуску, позначка «Новий», кнопка переходу на сайт. Якщо поля немає в API —
воно просто не показується; дані ніде не вигадуються.

## Дані та API

- Запит: `GET https://freeserp.ai/api.php?index=sites&category=ai&q=…&ai_categories=…&sort=…&order=…&from=…&size=…`
- API надсилає некоректний CORS-заголовок, тому браузер звертається до маленького
  PHP-проксі на тому ж домені (`api/freeserp.php`), який пропускає лише дозволені параметри.

## Технології

React 19, Vite, React Router, CSS Modules, Anime.js. Адаптивність: desktop 1440,
tablet 768, mobile 375. Стани завантаження, помилки (з кнопкою «Спробувати ще»)
та порожнього результату.
